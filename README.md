# Static Website – GitHub Pages Deployment

## 🌟 Objective
This project demonstrates how to build and deploy a simple, responsive static website using HTML and CSS, hosted directly on GitHub Pages.

## 🛠 Tools & Technologies Used
- **HTML5**: For page structure and content.
- **CSS3**: For styling and layout.
- **GitHub Pages**: For free static site hosting.
- **Git**: For version control and repository management.

## 📂 Project Structure
static-website/ ├── index.html # Main webpage ├── style.css # CSS for styling └── README.md # Project documentation

## 🚀 Steps Followed

1. **Project Setup**:
   - Created a basic HTML file with semantic tags.
   - Linked an external CSS file for custom styling.
   - Ensured the design is responsive using media queries.

2. **Version Control**:
   - Initialized a Git repository.
   - Pushed the code to a public GitHub repository.

3. **Deploying with GitHub Pages**:
   - Went to **Repository Settings > Pages**.
   - Set the source to the `main` branch and root folder.
   - GitHub Pages generated a live link for the site.

4. **Verifying Deployment**:
   - Opened the live URL to confirm layout, styling, and responsiveness.
   - Updated styles and pushed changes to see auto-updates.
